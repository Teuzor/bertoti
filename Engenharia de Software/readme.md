Atividade 1 - Trecho 1

O Trecho 1 descreve as diferenças entre as principais áreas da computação e engenharias, paralelamente explicando as características singulares de Engenharia de Software. Como exemplo
Ciência da Computação, tem como foco desenvolver habilidades e capacidades para conseguir empregos atuando como "programadores", escrevendo códigos. Engenharia de Software embora 
mantenha muitas semelhanças com Ciência da Computação, incrementa skills para utilizar seus conhecimentos teóricos para criar coisas "reais" e exatas. Outras engenharias como
Engenharia Mecânica, civil, aeronáuticas e etc também utilizam seus conhecimentos para criar coisas reais, no entanto, tem como diferença serem mais palpáveis.
